# ADRs moved

All Architecture Decision Records were consolidated into a single canonical
location under [`docs/adr/`](../../../../docs/adr/README.md) by TASK-005.

The legacy `ADR-001`…`ADR-006` files that used to live in this directory were
renumbered as `ADR-0003`…`ADR-0008`; see the
[legacy ID mapping](../../../../docs/adr/README.md#legacy-id-mapping).
